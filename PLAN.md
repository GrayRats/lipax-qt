## 9a. Детектор смены текста в кадре (`crates/core/src/detect.rs`)
- [x] Сигнатура — битовая карта блоков 4×4 px с контрастными краями букв (светлая сторона ≥ 140), один проход, целочисленно; области > 1 Мп читаются через пиксель
- [x] Плавная смена яркости и тёмный подвижный фон не считаются изменением
- [x] Курсор игры и подсветка (≤ 2 пятна до 128 px) игнорируются; пятно, стоящее на месте 1 с, засчитывается (короткие слова не теряются)
- [x] Разбросанное мерцание фона (< 12% текстовых блоков) игнорируется

- [x] Непрерывно меняющийся кадр: OCR не реже раза в 2 с (`MAX_UNSTABLE`), иначе субтитры поверх подвижной сцены не переводились
- [x] Настройка чувствительности задаёт порог контраста краёв: 40 + 8·value
