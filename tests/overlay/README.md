# Проверки LipaX 1.3.9

## Исторический прогон исправлений overlay

Исправлена загрузка geometry-скрипта KWin: запуск идёт через менеджер скриптов с
подтверждением `Ready`. Геометрия pinned/floating разделена, публикация настроек
не сбрасывает native resize, позднее восстановление позиции отменяется после
начала пользовательского движения. Inplace явно выбирает layer-shell output;
устаревшие события повторно проверяются на GUI-потоке.

Проверки: 456 Rust passed, 0 failed, 15 ignored; 126 основных QML и 18
регрессионных QML passed. Release-бинарник 1.3.9 успешно собран. Live pipeline
на Wayland и с XWayland-источником прошёл: обе независимые inplace-поверхности
сопоставлены с соответствующими областями снимка реального KWin.

Дополнительный прогон записанного CrossxMars.exe на актуальной сборке:
**1 passed**, `uncovered_text_blocks=[]`, `repeat_ocr_jobs=0`. Использованы
настоящий RapidOCR, Rust layout, общая production реализация Qt measurement
и QML rendering. Fixture и пороги не изменены. Предопределённые переводы
относятся только к этому offline-тесту; он не считается live проверкой игры.

- `overlay-regression-sources.tar.gz` — снимок новых исходников тестов с исходными
  путями `tests/inplace/`; запускать из полного рабочего дерева проекта.
- `evidence/` — сохранённые журналы выполненных проверок, снимки реального KWin
  и реальные буферы обеих inplace-поверхностей.
- `evidence/manifest.json` — команды, результаты и расположение первичных данных.

Основные исходники остаются в [`tests/inplace/`](../inplace/), чтобы действующие
runner и относительные QML imports продолжали работать. Все промежуточные данные
запусков находятся в `tmp/overlay-bugfix/`; сохранённая здесь копия результатов
сделана по запросу пользователя.

Открытые проверки: физические LMB drag/resize и MMB для floating, ручная активация
через task manager, несколько физических outputs с разными desktop origins,
отключение/подключение монитора и fractional scaling KWin. XTest не подтвердил
перемещение в текущей сессии. Live Portal и все live game/background комбинации
также не проверены; автоматические проверки typography/backgrounds сохранены.

`frame_submitted` означает отправку кадра Qt. Видимость обеих inplace-поверхностей
в выполненных live сценариях дополнительно подтверждена compositor screenshot.
Native Wayland восстанавливает глобальную позицию только через доступную
интеграцию KWin с проверкой результата; иначе используется placement композитора.

## Проверки исправленного пакета 1.3.9-2

Счётчики выше относятся к предыдущему прогону. Они не подтверждают автоматически
следующие изменения размещения. Журналы текущих проверок сохраняются отдельно
в `evidence/placement-quality/`; финальная сборка проверяется отдельно от
внешнего вида игровых переводов.

Постоянные примеры в `docs/screenshots/test-game/translations/` теперь используют
настоящий RapidOCR и локальный Bergamot. Общая стрессовая фраза не выдаётся за
перевод игрового текста. Примеры пользователя из `Эталоны/` служат визуальным
ориентиром, а не автоматически утверждёнными эталонами по пикселям.

Офлайн-проверка размеров и границ не означает, что весь текст на изображении
распознан и заменён. В JSON каждого примера отдельно указаны непринятые поля,
пропущенные переводы и размещения рядом с оригиналом. Такие размещения не
считаются заменой исходного текста.

Остаются ограничения качества: стилизованные и вертикальные надписи,
текст вокруг встроенных игровых значков, пропущенные OCR подписи и качество
отдельных переводов локальной модели. Успешная сборка пакета не закрывает эти
ограничения и не заменяет физические проверки floating и дисплейных конфигураций.
