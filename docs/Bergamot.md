# Локальный перевод Bergamot (Linux)

LipaX запускает нативный CLI [`bergamot`](https://github.com/browsermt/bergamot-translator).
Текст переводится на машине пользователя и не отправляется сетевому сервису.

1. В Arch-пакет LipaX включён движок `/usr/lib/lipax/bergamot`.
   Поле «Bergamot: путь к CLI» можно оставить пустым. Для своей сборки укажите
   исполняемый файл в этом поле или `BERGAMOT_BINARY`; при отсутствии встроенного
   движка также проверяется `PATH`. Установка одной модели не устанавливает CLI.
2. Выберите «Bergamot (локально)», исходный язык и язык перевода.
   Исходный язык может наследоваться от OCR; определение `auto` не поддерживается.
3. LipaX автоматически находит или скачивает модель и создаёт конфигурацию CLI.
   В настройках отображаются Found / Not Found / Downloading... и прогресс.

## Поиск и проверка

Порядок поиска для каждой пары (например, `en-ru`):

1. Путь из `translation.bergamot_model_paths`; затем прежний
   `translation.bergamot_models_dir` / `BERGAMOT_MODELS_DIR`, если задан.
2. `~/.local/share/LipaX/bergamot-models/en-ru/` (с учётом `XDG_DATA_HOME`).
3. Каталоги `bergamot-models` внутри профилей `~/.mozilla/firefox/`.
4. Загрузка с официального CDN Mozilla.

Модели Firefox копируются в кэш LipaX, поэтому удаление профиля Firefox не ломает
перевод. Поиск обходит каталоги профилей, но не читает внутренние IndexedDB/Cache API
базы Firefox и не следует симлинкам на каталоги профилей.

Все необходимые файлы модели, словаря (или двух словарей) и shortlist проверяются
по точному размеру и SHA-256 из встроенного каталога Mozilla. Существование `.bin`
само по себе не означает, что модель установлена. Неполные и повреждённые наборы
пропускаются. Загрузка идёт во временный каталог; только проверенный набор получает
окончательный путь и `<пара>.yml`. Путь сохраняется в настройках автоматически.

## Версии модели и обновление

Для многих пар Mozilla выпустила несколько наборов (например, `en-ru`: 2.1 — 33,6 МБ
и 2.0 — 44,5 МБ; 1.x — компактные модели около 20 МБ). Под строкой статуса LipaX
показывает, какая версия установлена (определяется по SHA-256 файлов, а не по имени),
и список версий пары с размерами.

- **Скачать выбранную версию** ставит выбранный набор вместо установленного; прежний
  остаётся на месте, пока новый не скачан и не проверен.
- **Обновить до X** появляется, если в каталоге есть набор новее установленного.
- Кнопка **Найти / скачать модель** по-прежнему принимает любую установленную проверенную
  версию и не заменяет её более новой сама.

«Новее» значит новее в каталоге, встроенном в эту сборку; сеть для проверки не нужна и
не используется. Новые модели Mozilla попадают в каталог при выпуске новой версии LipaX
(`cargo run -p lipa-core --example update_catalogs -- bergamot`). Скачивание начинается только по нажатию кнопки.

Кнопка **Set model path manually** принимает каталог с файлами модели либо прежний
YAML-конфиг Bergamot для текущей пары. Пустое значение возвращает автоматический
поиск. Ручные наборы тоже должны соответствовать одной из версий встроенного
каталога; произвольные сторонние модели не считаются проверенными.

Поиск, копирование, проверка и загрузка выполняются в отдельном **QThread**.
Сворачивание в трей не прерывает работу: подсказка трея показывает
`LipaX: Downloading model... 45%`. При выходе загрузка отменяется, временные файлы
удаляются, поток завершается до уничтожения Qt. При смене пары выполняющаяся
загрузка заканчивается; затем проверяется новая пара. Учитываются также языки
активных областей распознавания.

Без установленной модели при отсутствии сети интерфейс показывает:
`Translation model for en-ru is missing. Download it in Settings.`
После восстановления сети нажмите «Найти / скачать модель». Направления, которых
нет в каталоге, показывают отдельное пояснение; перевод через промежуточный язык
автоматически не строится.

## Каталог и обслуживание

`crates/core/src/translate/bergamot_catalog.json` — снимок стабильных версий
[Mozilla Remote Settings translations-models](https://firefox.settings.services.mozilla.com/v1/buckets/main/collections/translations-models/records)
от 2026-10-08. Файлы поставляются с официального CDN
`https://firefox-settings-attachments.cdn.mozilla.net/`, адрес которого опубликован
в [capabilities Mozilla](https://firefox.settings.services.mozilla.com/v1/).
Каталог включён в приложение, чтобы проверка ранее скачанных моделей работала
без интернета. Выбирается наиболее новая стабильная версия пары; другие версии
из снимка также принимаются при локальном поиске. Обновление каталога:
`cargo run -p lipa-core --example update_catalogs -- bergamot` (читает только список файлов Mozilla,
модели не скачивает).

CLI загружает модель на каждый новый запрос, который ограничен 45 секундами.
Повторные фразы обслуживает кэш LipaX. Автоматического перехода на облачный
переводчик при ошибке локального движка нет.

Движок собирается из закреплённого коммита Mozilla
`5ae1b1ebb3fa9a3eabed8a64ca6798154bd486eb` скриптом
`packaging/build-bergamot.sh`. Для сборки нужны Git, CMake, Ninja и PCRE2;
при сборке пакета они перечислены в `PKGBUILD`. Нативная сборка требует SSE4.1.
При отсутствии или неверном пути к движку автоматические повторы останавливаются;
после исправления пути выполните перевод заново или перезапустите слежение.
