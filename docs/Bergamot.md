# Локальный перевод Bergamot (Linux)

LipaX может запускать нативный CLI `bergamot` из проекта
[`browsermt/bergamot-translator`](https://github.com/browsermt/bergamot-translator).
Перевод выполняется на машине пользователя; текст не отправляется сетевому сервису.
В настройках «Сервис перевода» выберите «Bergamot (локально)».

1. Соберите нативный CLI по инструкции проекта. Укажите абсолютный путь к
   `build/app/bergamot` в поле «Bergamot: путь к CLI» либо в `BERGAMOT_BINARY`.
   Пустое поле также позволяет искать `bergamot` в `PATH`.
2. Получите совместимую модель нужного направления. Актуальный реестр моделей
   опубликован в [`mozilla/translations`](https://github.com/mozilla/translations);
   пример подготовки модели и вызова CLI есть в
   [`examples/run-native.sh`](https://github.com/browsermt/bergamot-translator/blob/main/examples/run-native.sh).
   Для нативного CLI нужен файл конфигурации Bergamot; файлы из реестра Mozilla
   могут потребовать преобразования в этот формат. Скрипт подготовки из примера
   относится к опубликованной там старой Marian-модели.
3. Создайте каталог конфигураций. Для каждой пары положите или создайте симлинк
   `<источник>-<цель>.yml` на подготовленный конфиг модели, например `en-ru.yml`
   или `ja-ru.yml`. Коды языков записываются строчными буквами. Укажите каталог
   в поле «Bergamot: каталог моделей» либо в `BERGAMOT_MODELS_DIR`.

LipaX разрешает симлинк на настоящий конфиг и запускает CLI из каталога модели,
чтобы относительные пути внутри неё работали. Отсутствующая пара даёт понятную ошибку.
Исходный язык берётся из настроек перевода или языка OCR; автоматическое определение
языка Bergamot не поддерживается. Загрузка моделей из сети не выполняется.

Запуск CLI не блокирует интерфейс Qt и ограничен 45 секундами. Этот вариант
загружает модель при каждом новом запросе, поэтому первый перевод фразы и новые
фразы могут быть медленными; повторные фразы обслуживает кэш LipaX. Постоянный
процесс с моделями в памяти потребует отдельного нативного worker. При ошибке
локального движка автоматического перехода на облако нет: это сохраняет локальность
перевода. Другой сервис можно выбрать вручную.
