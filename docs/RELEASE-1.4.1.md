# LipaX 1.4.1

Изменения относительно 1.3.9 (1.4.0 и 1.4.1) (режим «наложение текста», перевод, окружение для тестов).

## Наложение текста
- Опция `appearance.inplace.click_through` («Пропускать клики сквозь перевод», по умолчанию выключена): окно поля не принимает мышь, клики идут в игру. По умолчанию поле, как и раньше, принимает мышь, средняя кнопка скрывает наложение.
- Режим «Подмена текста»: после перерисовки считается доля пикселей поля, всё ещё похожих на старый текст (предел 1,5 %); при превышении фрагмент строится заново (сначала учитывается любой цвет букв, потом шире маска). Автоматический режим выбирает способ как раньше.
- Короткие метки (до 14 символов): слабое чтение, отличающееся от надёжного прошлого только похожими символами (`15`↔`is`, `0`↔`O`), игнорируется — без повторного перевода и перерисовки.

## Перевод
- Проверка ответа переводчика: пустой ответ, эхо исходного текста, потеря хвоста, потеря чисел; отклонённый ответ не кэшируется.
- Локальный Bergamot: все ожидающие тексты тика переводятся одним запуском процесса (построчный CLI), при несовпадении числа строк — откат на поштучный перевод.
- Кэш переводов работает за O(1).

## Смена диалога в режиме наложения
- Перевод прошлой реплики снимается, как только под полем меняется текст, и не остаётся поверх следующей (в живой проверке первое обновление наложения — через ≈0,26 с после нажатия Space).
- Два чтения одной строки, которые перекрывались и обе отбрасывались, склеиваются или заменяются более полным.
- Расчёт фона «Подмена текста» на крупных полях стал заметно дешевле.

## Прочее
- `LIPAX_RUNTIME_DIR` переопределяет каталог подложек, превью и KWin-скрипта (по умолчанию как раньше).
- KWin-захват области на всё окно не копирует кадр второй раз.
- В журнал при запуске пишется реальная платформа Qt (`qt platform=…`).

## Исправления 1.4.1
- Старый перевод снимается, когда под полем меняется текст (сигнатура расположения букв), и не остаётся над следующей репликой.
- Два чтения одной строки склеиваются или заменяются более полным (раньше обе отбрасывались).
- Расчёт фона «Подмена текста» на крупных полях стал заметно дешевле.
- Ложное отклонение перевода (потеря хвоста) смягчено.

## Окно игры и захват
- После перезапуска игры окно находится заново по паре (класс, заголовок); скрипт KWin присылает класс и заголовок каждого окна. Общие классы вроде `steam_app_default` без совпадения заголовка не угадываются, два одинаковых окна тоже.
- Выход по SIGTERM, SIGINT и SIGHUP равен `lipax --quit`: настройки сохраняются, скрипт выгружается из KWin (раньше процесс умирал мгновенно, и скрипты копились в KWin до его перезапуска). Второй сигнал завершает процесс сразу.

## Наложение: что нового
- Пока игра печатает реплику по буквам и кадр не устоялся, поле с растущим текстом не читается, пока рост не остановится (не дольше 8 с): нет частичных переводов.
- «Подмена текста»: поиск образца включается только для повторяющегося рисунка, а не для облаков и градиентов (там он вставлял светлые куски); заливка сглаживается релаксацией; обводка букв уходит вместе с ними. На узорных фонах полный фон считается в отдельном потоке: поле сразу получает быстрый патч и обновляется, когда полный готов.
- Межстрочный шаг, измеренный в оригинале, не опускается ниже 1,15 кегля (строки не слипаются).
- Новые опции (по умолчанию выключены): «Не переводить кнопки и пункты меню» (`appearance.inplace.skip_controls`) и «Не переводить имена персонажей» (`appearance.inplace.skip_names`).

## Скорость
- Детектор локального контраста (самая тяжёлая часть кадра) считает плоскости на нескольких потоках и без интегрального изображения: разбор кадра 2560×1080 в `begin()` 94 → около 25 мс. Поиск образца идёт на половине ядер (игре остаётся остальное).
- Проигрыш записанных кадров CrossxMars в тестах 152 → 49 с.

## Инструменты и проверки
- `examples/background_quality`: сравнение «подмены текста» с чистым фоном (ошибка, смещение яркости, шов, время).
- Метрика по эталонам (`tests/reference_metric.rs`, `tests/inplace/prepare-references.sh`): полнота замены, лишние блоки, площадь плашек за пределами текста. Кадры с переводом в `docs/screenshots` сделаны прежним движком, поэтому первые числа (полнота 75 %) описывают прошлое состояние.
- Замеры этапов `begin()` (`InplaceEngine::timings()`).
- Заметки о работе: `Improve_17-17.MD`, `TASK-PROSESS.MD`.

## Проверено и не проверено
- Проверено автотестами (Rust, QML) и офлайн-сравнением режима фона на 8 сохранённых кадрах.
- **Не проверялось вживую:** поведение в игре на KWin Wayland/XWayland, прохождение кликов при включённой опции, несколько мониторов, дробный масштаб, повторный поиск окна после настоящего перезапуска игры, удержание чтения при настоящей печати по буквам.
- Выход по сигналу проверен вживую (`kill -TERM`: код 0, скрипт выгружен из KWin); поиск окна — только на списке реальных окон KWin.
