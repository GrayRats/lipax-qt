# LipaX-QT — переработка GUI/UX главного окна

## Контекст и цель

Обновить интерфейс LipaX-QT на Qt 6/QML для KDE Plasma / KWin (Wayland и XWayland). Сделать главное окно компактным, понятным и устойчивым к длинным строкам OCR/перевода. Использовать приложенный комплект `icons/*.svg`. Сохранить существующие обработчики сигналов, настройки и функциональность приложения. Не менять логику OCR, захвата экрана и перевода без технической необходимости.

## 1. Верхняя панель

- Справа, в одной логической группе, расположить кнопки: **Предпросмотр распознавания**, **История переводов**, **Настройки**.
- **Настройки** — крайняя справа кнопка в верхнем правом углу. История и предпросмотр — непосредственно левее.
- Заменить текстовые подписи этих кнопок на SVG-иконки `ocr-preview.svg`, `translation-history.svg`, `settings.svg`.
- Сделать одинаковые размеры интерактивных областей и выровнять по одной базовой линии. Группа не должна перекрывать название выбранного процесса.
- Для каждой кнопки дать русскую всплывающую подсказку и доступное имя для клавиатуры/экранного диктора.

## 2. Отображение перевода и сброс области

- Заменить галочку **«Показать поверх исходного текста»** на иконку `show-inplace-overlay.svg`.
- Заменить галочку **«Показать окно перевода»** на иконку `show-translation-window.svg`.
- Обе кнопки — настоящие независимые переключатели: `checkable`, `checked`, состояние после повторного открытия должно соответствовать настройкам. Активное состояние выражено понятной подсветкой и/или фоном, а не сменой иконки на галочку.
- **«Сбросить область»** заменить иконкой `reset-capture-area.svg`, действие должно сбрасывать только заданную пользователем область, без непредусмотренного сброса остальных настроек.
- Для всех трёх кнопок добавить tooltip, Accessible.name, состояния hover/pressed/focus/disabled. Не использовать emoji или символы Unicode вместо SVG.

## 3. Компактный выбор области

- Уменьшить ширину выпадающего меню **«Название области окна»**: применять подходящий `implicitWidth`/`preferredWidth`, разумные ограничения и горизонтальную адаптацию по доступной ширине.
- Переместить поле правее, в одну строку с относящимися к области захвата элементами управления, если ширина позволяет.
- При узком размере окна использовать компоновку, которая предотвращает наложение/обрезание других элементов. Не вводить жёстких абсолютных `x/y`-координат для элементов адаптивной панели.
- Длинные значения списка сокращать визуально через elide; полное значение показывать во всплывающей подсказке. Содержимое сохранённых значений не изменять.

## 4. Окно не должно растягиваться от длинного перевода

- Исправить изменение размеров главного окна при длинных OCR-строках и переводах.
- Проверить и устранить неконтролируемое влияние `implicitWidth`, `implicitHeight`, `Text`, `TextEdit`, `ScrollView`, `ColumnLayout` и вложенных контейнеров на геометрию верхнего уровня.
- Длинный текст должен переноситься внутри выделенного блока. Если содержимое превышает доступную высоту, прокручиваться должно содержимое, а не изменяться размер окна.
- Уважать размеры, вручную заданные пользователем. Не изменять размеры окна программно после каждого нового перевода.
- Проверить длинные слова без пробелов, CJK-текст, многострочный перевод и изменение масштаба дисплея.

## 5. Сохранение расположения и размеров окон

- Добавить отдельную настройку **«Запоминать положение и размер окон»** — по умолчанию **включена**.
- Сохранять как минимум геометрию главного окна и отдельного окна перевода, а также целевой монитор для каждого окна, если соответствующая информация доступна.
- Восстанавливать геометрию после создания окна, без визуального скачка и повторного перезаписывания значений по мере инициализации.
- Хранить данные через принятый в проекте механизм конфигурации (например, QSettings), не вводить второй независимый конфиг.
- При отключении опции не перезаписывать сохранённую геометрию и не применять её при следующем открытии.
- Если монитор отключён, его идентификатор изменился, масштабирование отличается или окно попадает вне рабочей области, выбирать доступный экран и безопасно ограничивать геометрию его `availableGeometry`.
- Учесть ограничения Wayland/KWin: клиент не всегда может установить абсолютные координаты окна. Не обещать точного восстановления позиции там, где это запрещено композитором. Обеспечить максимально возможное восстановление с корректным fallback и без навязчивых повторных перемещений.

## 6. Название выбранного процесса

- Отображать название выбранного процесса **подчёркнутым текстом** (underline в оформлении, не вставляя символ `_` внутрь реального имени).
- Сохранять одну строку. При нехватке места постепенно уменьшать размер шрифта до **8 px**.
- Если даже при 8 px строка не помещается, использовать `ElideRight` и tooltip с полным оригинальным именем процесса.
- Название не должно вытеснять кнопки из правой части верхней панели; учитывать свободную ширину.

## 7. Индикатор рабочего состояния

- Вместо постоянного текста **«Работает» / «Остановлен»** использовать компактный цветовой индикатор в **правом нижнем углу**, непосредственно над самой нижней строкой состояния или в её правой части при наличии места.
- Цвета: зелёный — работает (`status-running.svg`); серый — остановлен (`status-stopped.svg`); янтарный — выполняется обработка (`status-processing.svg`); красный — ошибка (`status-error.svg`). Последние два состояния использовать только если они реально существуют в модели приложения.
- Состояние Running/Processing допускает плавную, ненавязчивую анимацию пульса (ориентир 1.8–2.2 с), без частого мерцания. Для Stopped — статичный индикатор. Для Error — явно различимый статичный или медленно пульсирующий индикатор.
- Отключать анимацию при системном режиме reduced motion (если механизм доступен), а также когда окно скрыто, если это уменьшает ненужную нагрузку.
- При наведении показывать текст состояния по-русски, а для доступности задавать `Accessible.name` и понятное описание. Не полагаться исключительно на цвет.

## 8. Самая нижняя строка: только английские сообщения

- Нижнюю строку оставить для краткого текста **о текущем действии или событии**, а не дублировать индикатор состояния.
- Сообщения **этой строки** должны быть исключительно на английском, например: `Ready`, `Scanning text…`, `Translating…`, `Translation updated`, `Capture region cleared`, `Error: ...`.
- Русскую локализацию остальных элементов приложения не менять. Ошибки не скрывать: сохранить технические детали в логах; длинные строки в UI обрезать через elide с возможностью увидеть полный текст.
- Никакое сообщение не должно увеличивать ширину главного окна.

## 9. Общие UX и технические требования

- Сохранить существующие сигналы, подключения, переключатели, hotkeys, состояние авто-перевода и обработку ошибок.
- Стандартный размер рисунка SVG — **20–22 px** при области нажатия порядка **34–36 px**; 24×24 viewBox.
- Единые отступы, закругления, hover/pressed/focus и контраст в светлой и тёмной теме.
- Базовые монохромные SVG перекрашивать через поддерживаемый Qt Quick механизм, не полагаясь на CSS `currentColor` внутри SVG. Цветные SVG индикаторов состояния оставлять семантическими.
- Использовать компоненты QML и layout-менеджеры, принятые в проекте; не создавать дублирующую систему управления окном.
- Иконки должны входить в CMake/qrc/пакет приложения, без обращений к внешним файлам по абсолютным путям.
- Не менять существующие названия и поведение настроек за рамками указанного ТЗ без причины.

## 10. Проверка и критерии готовности

1. В правом верхнем углу подряд: предпросмотр, история, настройки; настройки — последняя кнопка справа.
2. Оба режима отображения переключаются и явно показывают `checked`, сброс области корректно отрабатывает.
3. Список областей компактнее и находится правее; элементы не накладываются друг на друга.
4. Очень длинный текст перевода не растягивает окно и остаётся доступен через перенос/прокрутку.
5. С включённым сохранением восстанавливаются размеры и, насколько позволяет композитор, положение и монитор; при отключённом — опция не применяется.
6. Название процесса подчёркнуто, уменьшается до 8 px, дальше сокращается с подсказкой полного имени.
7. Индикатор состояния расположен снизу справа, состояния различимы и анимация ненавязчива.
8. Нижняя строка содержит только английские сообщения и не меняет размеры окна.
9. Проверить KDE Plasma/KWin Wayland и XWayland, один и два монитора, отключение монитора, HiDPI, светлую/тёмную тему, управление клавиатурой и повторный запуск.
10. Представить список затронутых файлов, перечень исправлений, результаты фактических проверок и известные ограничения, не объявляя непроверенное протестированным.
