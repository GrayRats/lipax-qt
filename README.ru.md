# LipaX

[English version](README.md)

**Перевод игрового текста для Linux — в отдельном окне или поверх оригинала.**

LipaX захватывает выбранное окно игры, распознаёт текст и показывает перевод. Рассчитан на **KDE Plasma 6 / KWin / Wayland**. Интерфейс — системный Qt написанный на 6.12+ LTS и QML, обработка кадров — чистый Rust.

<a id="возможности"></a>
## Возможности

- **Перевод во время игры.** Автоматическое слежение за текстом или разовый перевод по команде. Повторяющиеся фразы берутся из кэша.
- **До трёх областей захвата.** Субтитры, диалоги и меню читаются отдельно. Каждую область можно выключить и задать ей свои языки и движок распознавания.
- **Два вида отображения.** Отдельное окно перевода поверх игры или наложение на исходный текст с подгонкой размера и переносов.
- **Несколько движков распознавания.** Tesseract, RapidOCR (PP-OCRv5), MeikiOCR (японский), PaddleOCR и режим «Авто» с повторным чтением при низкой уверенности.
- **Локальный и сетевой перевод.** Bergamot, Google Translate, Yandex Translate, DeepL, Microsoft Translator и собственный API.
- **Подбор шрифта оригинала.** В режиме наложения анализируются засечки, ширина букв, моноширинность, насыщенность и наклон. Подходящее семейство выбирается из 36 встроенных шрифтов, включая игровые наборы. Для PT Serif доступен настоящий курсив. Это подбор похожего начертания, а не определение точного названия шрифта.
- **Оформление.** Шрифт, цвет текста, фон, рамка, прозрачность, скругление, тень и обводка. Окно перевода можно закрепить, перемещать и прокручивать, если текст длинный.
- **Профили игр.** Области и параметры обработки запоминаются для выбранной игры при захвате через KWin.
- **Управление без переключения окон.** Настраиваемые горячие клавиши и системный трей. При сворачивании в трей перевод продолжается после закрытия главного окна.
- **История и проверка OCR.** История оригиналов и переводов с копированием, просмотр распознанного текста, ручные фильтры изображения и автоподбор обработки кадра.
- **Диагностика.** Вкладка «Статус» показывает готовность движков, моделей и компонентов захвата. Журнал помогает разобраться с ошибками.

<a id="подробности"></a>
## Подробности

### Bergamot: перевод без интернета

Bergamot переводит текст на вашем компьютере, без отправки сетевому сервису. **Нативный движок входит в Arch-пакет LipaX**, поэтому поле «Bergamot: путь к CLI» можно оставить пустым.

При выборе языковой пары LipaX ищет модель в таком порядке: сохранённый путь, собственный кэш и каталоги моделей в профилях Firefox. Найденные файлы Firefox копируются в кэш LipaX. Если подходящей модели нет, приложение скачивает её с официального CDN Mozilla и сохраняет путь в настройках.

- Все файлы проверяются по размеру и SHA-256. Незавершённая загрузка моделью не считается.
- Поиск и загрузка идут в фоне. Прогресс виден в настройках и в подсказке трея, а сворачивание приложения загрузку не прерывает.
- Свою установку модели можно указать вручную: **Set model path manually**. Ручной набор тоже должен совпадать с проверенными моделями из каталога.
- После установки перевод работает без сети. Первая загрузка модели требует интернета. Доступны только направления из каталога, автоматического перевода через промежуточный язык нет.

Кэш по умолчанию: `~/.local/share/LipaX/bergamot-models/<пара>/` (с учётом `XDG_DATA_HOME`). Подробнее: [настройка Bergamot](docs/Bergamot.md).

### Распознавание: движки

| Движок | Что нужно | Особенности |
|---|---|---|
| **Tesseract** | Языковые данные `tesseract-data-*` | Движок по умолчанию. Поддерживает несколько языков сразу. Английские данные входят в зависимости Arch-пакета. |
| **RapidOCR (PP-OCRv5)** | ONNX Runtime и модель из настроек | Работает внутри приложения, без Python. Модель выбирается по основному языку. Можно задать число потоков и GPU, если установленная библиотека с ним собрана. |
| **MeikiOCR (японский)** | ONNX Runtime и модель из настроек (около 46 МБ, LGPL-3.0) | Работает внутри приложения, без Python. Читает японский текст игр, включая вертикальный. |
| **PaddleOCR** | Окружение Python с PaddleOCR | Необязательный движок. Читает основной язык. Установка описана в отдельной инструкции. |
| **Авто** | Tesseract и подключённые движки | Если Tesseract не уверен, пробует MeikiOCR (японский, при наличии модели), затем RapidOCR, а если тот недоступен — PaddleOCR. |

**Модели RapidOCR и MeikiOCR скачиваются только по кнопке «Скачать»** во вкладке «Распознавание». При смене языка приложение предлагает скачать недостающую модель, но само ничего не загружает. Размеры и SHA-256 проверяются перед установкой. Для распознавания сеть не нужна.

Источники моделей: [RapidAI/RapidOCR](https://github.com/RapidAI/RapidOCR) и [rtr46/meikiocr](https://github.com/rtr46/meikiocr). Инструкции: [RapidOCR](docs/RapidOCR.md), [MeikiOCR](docs/MeikiOCR.md), [PaddleOCR](docs/PaddleOCR.md).

### Сервисы перевода

| Сервис | Что нужно |
|---|---|
| **Bergamot** | Модель языковой пары. API-ключ не нужен. |
| **Google Translate** | Интернет. |
| **Yandex Translate** | API-ключ и folder ID во вкладке «Перевод». |
| **DeepL** | API-ключ во вкладке «Перевод». |
| **Microsoft Translator** | API-ключ и регион ресурса. |
| **Свой API** | Адрес сервиса и, если нужно, ключ доступа. |

Облачные сервисы получают распознанный текст. При ошибке Bergamot приложение не переключается на облачный сервис само.

Кэш уменьшает число повторных запросов. В отдельном окне перевода можно включить режим «Переводить только изменения»: неизменный текст берётся из кэша, а новые абзацы переводятся отдельно, без общего контекста.

### Захват и наложение

LipaX использует KWin ScreenShot2, а запасным вариантом служит захват через Portal. Наложение на исходный текст требует геометрию окна от KWin. **При захвате через Portal перевод выводится в отдельное окно.**

Средняя кнопка мыши на окне перевода переключает закрепление. В режиме наложения она скрывает перевод, вернуть его можно переключателем в главном окне. Показ поверх полноэкранной игры и размещение на мониторах с разным масштабом зависят от окружения.

<a id="быстрый-старт"></a>
## Быстрый старт

1. **[Установите LipaX](#установка)** и запустите `lipax` из меню приложений или терминала.
2. **Распознавание.** Во вкладке «Распознавание» выберите язык текста в игре. Для первого запуска подойдёт Tesseract; проверьте, что для языка установлены данные.
3. **Перевод.** Во вкладке «Перевод» выберите язык перевода и сервис. Для локального перевода выберите **Bergamot (локально)**, укажите исходный язык и дождитесь статуса **Found**. Автоопределение исходного языка Bergamot не поддерживает.
4. **Область.** Нажмите «Выбрать окно», затем «Выбрать область» и обведите субтитры, диалог или меню. Небольшая область с текстом обычно работает лучше, чем весь кадр.
5. **Запуск.** Выберите вид перевода и нажмите «Запустить автоперевод». Дополнительные области настраиваются во вкладке «Область».

Если перевод не появился, откройте «Просмотр OCR» и проверьте, читается ли оригинал, затем посмотрите вкладку «Статус». Для RapidOCR сначала установите ONNX Runtime и скачайте модель в настройках. Чтобы перевод работал при закрытом главном окне, включите «Сворачивать в системный трей при закрытии».

<a id="установка"></a>
## Установка

### Готовый пакет для Arch Linux

Если у вас есть файл пакета, например `lipax-1.3.5-1-x86_64.pkg.tar.zst`, установите его командой:

```bash
sudo pacman -U ./lipax-1.3.5-1-x86_64.pkg.tar.zst
```

Пакет ставит команду `lipax`, ярлык приложения, встроенные шрифты и движок Bergamot. Модели перевода и OCR скачиваются отдельно, через настройки. После обновления закройте LipaX через меню трея и запустите снова.

Пакеты публикуются на [странице релизов](https://github.com/GrayRats/lipax-qt/releases).

### Сборка из исходников (Arch Linux)

```bash
sudo pacman -S --needed base-devel git
git clone https://github.com/GrayRats/lipax-qt.git
cd lipax-qt
makepkg -si
```

Сборка скачивает исходники движка Bergamot с GitHub (`mozilla/bergamot-translator` и подмодули), поэтому нужен интернет.

Чтобы собрать текущие файлы проекта, включая локальные правки, используйте скрипт:

```bash
./packaging/build-local.sh -s
sudo pacman -U dist/lipax-1.3.5-1-x86_64.pkg.tar.zst
```

Дополнительные компоненты ставятся по необходимости:

| Задача | Что установить |
|---|---|
| Русский текст через Tesseract | `sudo pacman -S tesseract-data-rus` |
| Другой язык через Tesseract | Пакет `tesseract-data-*` нужного языка. Состояние языков видно в настройках. |
| RapidOCR на процессоре | `sudo pacman -S onnxruntime-cpu`, затем модель в настройках. |
| PaddleOCR | Окружение по [инструкции](docs/PaddleOCR.md). |

### Локальный запуск для разработки

Чтобы проверить захват через KWin, запускайте приложение скриптом:

```bash
./packaging/run-local.sh
```

Скрипт собирает приложение и регистрирует скрытую desktop-запись для пути к локальному бинарнику. Уже собранный бинарник запускается так:

```bash
LIPAX_LOCAL_BINARY=/полный/путь/к/lipax ./packaging/run-local.sh
```

Сначала закройте другой экземпляр LipaX: повторный запуск передаёт команды уже работающему приложению. Установленное приложение регистрацией не затрагивается. Убрать регистрацию локальной сборки: `./packaging/run-local.sh --unregister`.

<a id="диагностика-и-ограничения"></a>
## Диагностика и ограничения

| Симптом | Что проверить |
|---|---|
| OCR не видит текст или читает мусор | Язык и данные OCR, границы области, «Просмотр OCR», фильтры и порог уверенности. |
| Нет модели Bergamot | Подключитесь к сети и нажмите «Найти / скачать модель»; дождитесь статуса **Found**. |
| Bergamot не запускается | Проверьте, что установлен пакет со встроенным движком. Поле пути к CLI для штатного пакета можно оставить пустым. |
| RapidOCR сообщает об отсутствии библиотеки или модели | Установите ONNX Runtime, скачайте модель во вкладке «Распознавание» и нажмите «Проверить снова». |
| Сервис перевода вернул HTTP 429 | Превышен лимит запросов. Подождите и повторите перевод. Автоповторы после 429 останавливаются. |
| `ScreenShot2.Error.NoAuthorized` | KWin не разрешил захват этому бинарнику. Для локальной сборки используйте `packaging/run-local.sh`, для установленной — перезапустите приложение после обновления. |
| Наложение не работает | Проверьте источник захвата: Portal не сообщает положение выбранного окна. |

KWin связывает разрешение ScreenShot2 с путём исполняемого файла из desktop-записи. Ярлык пакета указывает на `/usr/bin/lipax`, а не на `target/debug/lipax`. Если кэш KDE устарел, выполните `kbuildsycoca6`. Вкладка «Статус» показывает готовность захвата.

Если сохранённая настройка не применилась к открытому окну или захвату, полностью закройте приложение и запустите снова. Совместимость наложения с конкретной полноэкранной игрой и размещение между мониторами с разным масштабом проверьте в своём окружении.

Журнал при запуске из терминала:

```bash
RUST_LOG=debug lipax
RUST_LOG=debug lipax 2>&1 | tee lipax.log
```

По умолчанию работает уровень `INFO`; `ERROR` выводится в stderr, остальное — в stdout.
